# Control de Pases de Salida — V5 corregida

Esta versión conserva el diseño completo de la V4 y modifica únicamente la plantilla del pase.

## Estructura
- `index.html` — interfaz y tres secciones.
- `style.css` — diseño V4.
- `app.js` — verificación, formulario, navegación y generación PNG.
- `assets/sep.png` — logo SEP.
- `assets/cbtis.png` — logo CBTIS/DGETI.
- `assets/escudo.png` — Escudo Nacional.
- `assets/fondo.mp4` — video de fondo (coloca aquí tu archivo).

## Correcciones del pase
- Logos reales en el encabezado.
- Fecha y grupo en el mismo renglón.
- Nombre, motivo y hora en sus líneas correspondientes.
- Después de HORA solamente aparecen `A-D 2023` y el escudo.
- Se eliminó la firma del responsable.
- Se eliminó el texto/icono de Control Escolar.
- Se conserva el folio lateral `702`.
- La altura de la imagen se ajustó para evitar el espacio inferior innecesario.

Abre `index.html` en el navegador. Para el video, coloca `fondo.mp4` dentro de `assets/`.
